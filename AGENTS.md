- Overlay hit testing is pass-through by default: the anchor/root and every root child are `pointer-events: none` except the actual surfaces (on-demand panels, compact access point/menu, seed layer), and panel chrome (`bv-panel`) is `none` with `auto` on header/footer/resize/controls/`.bv-feed` so empty body space and the settings menu stay reachable. Minimal defaults to detection evidence plus that one access point; popup panel/evidence visibility preferences are stored per video. The court projection over the video has exactly one toggle — **Court projection** in the evidence panel (`data-bso-court-projection-toggle` → `courtLinesByVideo` / `SET_COURT_LINES`, bright `--court-setup-line/--court-setup-net` tokens); the retired second "Court setup lines" control was the same rendering and was consolidated. The stroke feed (`.bv-feed`, including the manual panel's saved list) renders every row in a bounded scrollable body.
