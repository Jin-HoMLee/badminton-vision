Tiny read-only status label: `IN`/`OUT`, `suggested`/`accepted`/`corrected`/`unclassified`, `auto`/`manual` provenance.

```jsx
<Badge tone="in">IN</Badge>
<Badge tone="unknown">unclassified</Badge>
```

10px uppercase with 0.09em tracking. Tinted background + matching text, never a solid fill — solid fills are reserved for the primary Button.
